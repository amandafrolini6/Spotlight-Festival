# 🎬 Spotlight — Festival de Cinema Independente
 
Site institucional desenvolvido para o **festival fictício Spotlight**, criado como projeto acadêmico para a **UpperCase de Barra Bonita**, no curso **Fdevs 2026**. O objetivo foi construir um site estático, responsivo e semântico, aplicando boas práticas de HTML, CSS e acessibilidade.

> 🚧 **Projeto em desenvolvimento** — algumas páginas e funcionalidades ainda estão sendo ajustadas e podem sofrer alterações.
## 🔗 Páginas
 
| Página | Arquivo | Descrição |
|---|---|---|
| Início | `index.html` | Hero de abertura, seção "Sobre o evento" e chamada para inscrição |
| Programação | `programacao.html` | Grade de exibições e seção de palestrantes convidados |
| Ingressos | `ingressos.html` | Informações de ingressos, contato e formulário de mensagem |

## 🎨 Tecnologias
 
- **HTML5** semântico
- **CSS3** puro (variáveis CSS em `:root`, sem frameworks)
- **JavaScript** vanilla (interações de menu e formulário)
- Fontes do Google Fonts: `Cormorant Garamond` (títulos/serifada) e `Inter` (textos/sans-serif)
